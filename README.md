# 示例与「翻车案例」

这些例子展示工具的两端，并且都可以离线复现。它们是 README 里「经典翻车案例」的正文。

| 案例 | 输入 | 生成报告 | 结果 |
|---|---|---|---|
| 营销号伪史 | [pseudo-history.json](pseudo-history.json) | [pseudo-history.report.md](pseudo-history.report.md) | **0/100，低** |
| 先秦出土文献 | [excavated-bamboo.json](excavated-bamboo.json) | [excavated-bamboo.report.md](excavated-bamboo.report.md) | **80/100，高**（孤证豁免 + 整理本 +2） |

## 复现

```bash
pnpm demo
```

`generate.mjs` 读取两个 JSON，调用 `buildReport()`，重新写出两份 `.report.md`。

## 看什么

### 低分案例：营销号伪史

- 十二条准则几乎全部 `weaken`：匿名野史、孤证、无实物、晚出转述、文体不合、循环论证、文学笔法、现代想象倒推。
- 结果 `0/100`，等级「低」；「孤证不立」等硬规则继续压低上限。
- 它演示的是：**当一条记载在内外考证上都站不住时，工具不会因为「听起来很刺激」而给分。**

### 高分案例：先秦出土文献

- 「多源佐证」仍判 `weaken`（传世文献无同文），但调用者用 `override` 豁免了「孤证不立」，理由写在报告里。
- 实物史料、时空距离、文体格式、逻辑一致性等判 `support`；`edition: "peer-reviewed"` 另加 2 分。
- 结果 `80/100`，等级「高」；报告同时显示「豁免理由由调用者提供，工具不核验」。
- 它演示的是：**出土文献可以凭实物载体与整理报告获得较高基础信任，但豁免必须留痕、可复核。**

## 注意

- 两个案例都是**演示数据**，其中「营销号伪史」是虚构文本；「清华简」一段用于展示出土文献的评分路径，不构成对该段释文的专门考据。
- 豁免理由只是「调用者声明」，工具不核验。真实研究请回到原典、整理报告与考古材料。
